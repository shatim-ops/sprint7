# Задание 2. Подготовка базы знаний

## Зачем понадобилась подмена терминов

RAG проверяется только на том материале, которого модель не видела при обучении.
Если загрузить статьи из открытой энциклопедии, модель ответит по памяти, поиск
по индексу будет формальностью, и понять, работает ли пайплайн, станет нельзя.
Поэтому база собрана в два шага: сначала исходные документы, потом полная замена
всех узнаваемых имён на вымышленные.

## Что взято за основу

Вселенная Star Wars, справочные материалы ru.starwars.fandom.com. Выбрал её по
трём причинам: большой объём связанных сущностей, устойчивая внутренняя логика
и то, что модель эту вселенную знает наизусть, а значит любой ответ по памяти
сразу будет заметен.

Исходные документы лежат в `source_raw/`, по одному файлу на сущность, всего 44:
персонажи, планеты, корабли, технологии, организации и события. Каждый документ
это конспект в едином формате: короткое определение, затем разделы по 3 до 5
абзацев и блок связей с другими сущностями. Единый формат нужен не для красоты:
он даёт предсказуемые границы чанков при разбиении.

## Как устроена подмена

Словарь лежит в `terms_map.json`, в нём 287 правил. Формат простой:

```json
"Вейдер*": "Велгор",
"Звезда Смерти": "Цитадель Рока"
```

Ключ со звёздочкой это основа слова: скрипт сохраняет окончание, поэтому
"Вейдера" превращается в "Велгора", а "Вейдером" в "Велгором". Ключ без
звёздочки заменяется целиком и только как отдельное слово.

С русским языком наивная замена по подстроке не работает, и это главная
сложность задания. Пришлось учесть три вещи.

1. **Склонение.** Замены подобраны так, чтобы тип склонения совпадал с исходным.
   Мужское имя меняется на мужское с тем же типом основы, несклоняемое на
   несклоняемое. Иначе получается "у Соло" превращается в "у Марро" с неверным
   падежом. Там, где совпадения добиться нельзя, в словаре перечислены явные
   формы: "ситхи" в "ноксы", а не "нокси", как дало бы механическое правило.
2. **Границы слова.** Регулярка проверяет, что слева и справа нет буквы, иначе
   "Мол" находится внутри слова "молодой". При этом дефис границей считается,
   чтобы отрабатывали "мастер-джедай" и "гранд-мофф".
3. **Регистр.** Замена регистрозависимая. Это позволяет заменить "Силу" как
   название явления и не трогать "силой мысли" и "приливные силы", которые
   остаются обычными русскими словами.

Порядок применения важен: правила сортируются по длине ключа от длинных к
коротким, иначе короткое правило съест часть длинного словосочетания.

## Как проверяется результат

Отдельный скрипт `scripts/check_leaks.py` прогоняет готовую базу по стоп-листу
из 180 с лишним слов и основ исходной вселенной. Любое совпадение это ошибка
словаря. Проверка вынесена в тест `tests/test_corpus.py`, то есть падает вместе
со сборкой, а не обнаруживается на защите.

```
$ python scripts/build_corpus.py
Документов обработано: 44
Замен выполнено: 1442
Правил в словаре: 287
Результат: knowledge_base/

$ python scripts/check_leaks.py
Стоп-слов не найдено, проверено файлов: 44
```

## Что получилось

- `source_raw/` 44 исходных документа.
- `knowledge_base/` 44 документа с подменёнными терминами, в шапке каждого
  title, category и doc_id. Имя файла собирается из нового заголовка, поэтому
  по именам файлов исходную вселенную тоже не восстановить.
- `knowledge_base/injected/incident_note.txt` вредоносный документ для Задания 5,
  лежит в той же базе и индексируется наравне с остальными.
- `terms_map.json` словарь замен.
- `scripts/build_corpus.py` сборка, `scripts/check_leaks.py` проверка.

Примеры соответствий:

| Было | Стало |
|---|---|
| Дарт Вейдер | Вран Велгор |
| Люк Скайуокер | Деран Кестрел |
| Звезда Смерти | Цитадель Рока |
| Сила | Вейра |
| Татуин | Кадрин |
| Орден джедаев | Орден сайферов |
| Тысячелетний сокол | Серый Кайрос |

Логика мира при этом сохранена: родственные связи, последовательность событий и
причинно-следственные цепочки остались на месте, поэтому вопросы вида "кто кого
обучал" и "почему станция оказалась уязвимой" имеют однозначный ответ в тексте.
